
# CitySaathi – AI-Powered Civic Complaint Management System

## Overview
CitySaathi is a civic technology project designed to help citizens report and track local problems such as potholes, garbage, drainage issues, and broken streetlights.

## Features
- Submit and track civic complaints
- Record complaint locations when supported
- Organize complaints by category and status
- Suggest complaint priorities
- Explore duplicate complaint detection
- Provide an authority dashboard if implemented

## Tech Stack
- HTML
- CSS
- JavaScript
- NLP / AI components, where implemented
- Geolocation API, where implemented
